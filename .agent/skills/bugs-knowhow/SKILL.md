# Bug Knowhow Skill

## Description
This skill is responsible for documenting every bug found and fixed in the project to build a knowledge base.

## Protocol
Whenever a bug is fixed, record the following details:
1. **Error**: Description of the observed behavior.
2. **Cause**: Root cause analysis (why it happened).
3. **Applied Solution**: The code changes or configuration adjustments made to fix it.
4. **Future Prevention**: Steps or rules to ensure this specific bug never returns.

## Usage
Append new entries to `.agent/skills/bugs-knowhow/history.md` (create it if it doesn't exist).
