# Next.js Review Workflow

## Cuándo usar
Usa este comando al crear o modificar páginas, rutas o componentes en Next.js.

## Pasos
1. **Cargar la Skill**: Leer `.agent/skills/nextjs-review/SKILL.md`.
2. **Server vs Client**: Verificar directivas `'use client'` y optimizar el bundle.
3. **Data Fetching**: Validar revalidación de caché y renderizado eficiente.
4. **Performance**: Comprobar lazy loading e imágenes optimizadas con Next Image.
