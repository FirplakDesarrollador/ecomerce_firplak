# Code Review Workflow

## Cuándo usar
Usa este comando antes de fusionar o desplegar cambios para auditar calidad y estándares.

## Pasos
1. **Cargar la Skill**: Leer `.agent/skills/code-review/SKILL.md`.
2. **Analizar Archivos**: Revisar cambios recientes, sintaxis y tipado TypeScript.
3. **Aplicar Reglas**: Validar cumplimiento de reglas en `.agents/rules/`.
4. **Reportar**: Generar reporte de mejoras y advertencias.
