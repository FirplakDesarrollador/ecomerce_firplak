# Documentación de Módulos

Este directorio contiene un archivo `.txt` por cada módulo del proyecto.

## Convención
- Un archivo por módulo: `<nombre-modulo>.txt`
- La plantilla está en `/agents/workflow.md` y en `_plantilla-modulo.txt`
- Se crea en la **Fase 4** del flujo de desarrollo

## Contenido obligatorio de cada `.txt`
1. Nombre del módulo
2. Última actualización (fecha)
3. Descripción general
4. Tablas y vistas de las que depende en base de datos
5. Endpoints, conexiones SAP, conexiones Microsoft
6. Historial de actualizaciones
