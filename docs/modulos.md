# Documentación de Módulos

Este archivo contiene la descripción técnica de cada módulo del sistema.

## 1. Módulo de Autenticación
- **Ubicación**: `/app/(auth)`
- **Descripción**: Maneja el inicio de sesión, registro y recuperación de contraseña.

## 2. Módulo de E-commerce
- **Ubicación**: `/app/(shop)`
- **Descripción**: Catálogo de productos, carrito de compras y proceso de pago.

## 3. Módulo de Administración
- **Ubicación**: `/app/admin`
- **Descripción**: Gestión de inventario y pedidos.
