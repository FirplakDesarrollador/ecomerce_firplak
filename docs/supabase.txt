NOMBRE DEL MÓDULO   : Conexión Supabase (Database Layer)
ÚLTIMA ACTUALIZACIÓN: 10/06/2026

--------------------------------------------------------------------------------
DESCRIPCIÓN GENERAL
--------------------------------------------------------------------------------
Este módulo provee la conexión centralizada a la base de datos Supabase para
toda la aplicación, utilizando @supabase/ssr. Soporta clientes tanto
para Server Components (ssr) como para Client Components (edge/browser).
Sigue la arquitectura obligatoria de 4 capas.
