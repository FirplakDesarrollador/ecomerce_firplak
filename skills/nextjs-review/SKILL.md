# Next.js Review Skill

## Description
Ensures that the implementation follows the latest Next.js 15 patterns and features.

## Checklist
- Proper use of Server and Client Components.
- Route Handler implementation.
- Middleware usage for security/routing.
- Efficient data fetching (Caching, Revalidation).
- Compliance with the latest breaking changes documented in `node_modules/next/dist/docs/`.
